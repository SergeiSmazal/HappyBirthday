# 🌸 Happy Birthday — Interactive 3D Calligraphy & Blossom Experience

An interactive birthday greeting web page, created with love for my wife. The project combines traditional Chinese calligraphy art, poetry, and modern 3D animations using Canvas and CSS3.

## 🎨 Concept

The main idea of the project is **"Birth of Poetry from the Tree"**. The website is a cinematic 3D scene where an interactive cherry blossom tree literally "gifts" the lines of the poem:

* **Petal-by-Petal Emission (`1 petal = 1 character`):** Golden-lit petals fly from the tree crown, each following an individual 3D trajectory to the center of the screen.
* **Magic of Calligraphy:** Upon reaching the center, a petal flashes and transforms into an elegant Chinese calligraphy character with an ink-wash effect.
* **Dynamic Color:** The characters flash bright gold (`#D4AF37`) before transitioning into a deep, noble ruby-maroon shade (`#8b1e23`).
* **3D Flight & Stamping:** Once formed, the entire line tilts in 3D space, glides into its final position in the left text block with a motion-blur (trail) effect, and "stamps" onto the page.
* **Translation and Red Seal:** Beneath each fixed line, the English translation appears, and at the end of the animation, a traditional scarlet Chinese seal **«愛» (Love)** is applied.

---

## ✨ Key Features

* **Interactive Canvas (`love.js`):** A blooming tree with physics-based falling petals and scripted animation control.
* **Deep 3D Perspective:** Utilizing CSS 3D Transforms (`perspective`, `rotateY`, `translateZ`) to create a cinematic stage effect.
* **Poetic Fusion:** A harmonious blend of the original Chinese text (*"Song of Everlasting Regret"* by Bai Juyi) and an elegant English translation.
* **Responsive and Clean Design:** Minimalist code structure, focusing entirely on visual experience, color, and smooth performance.

---

## 🛠️ Tech Stack

* **HTML5:** Structured markup with 3D layer support.
* **CSS3:** Complex `@keyframes` animations, 3D transformations, text gradient fills (`background-clip: text`).
* **JavaScript (ES6+) & HTML5 Canvas API:** Managing petal physics, timing, and animation sequences.
